# Research analysis

`analysis/` contains the statistical and network analysis source: contingency analysis, graph layers, tensor semantics, path/rule motifs, degree-based null models, network models, robustness comparisons, brokerage/hierarchy, predictive checks, sensitivity analysis, validation, and figures.

The numbered scripts share `analysis/common.py`. Run a selected file from the repository root, for example `python research/analysis/01_contingency.py`, after installing `requirements-research.txt` and providing its expected inputs. `common.py` anchors resources at this directory.

`inputs/`, `recovered_source/`, and `results/` are ignored. Private research tables, source material, editorial documents, and generated figures are not distributed.
